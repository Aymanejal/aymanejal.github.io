# Portfolio — Aymane Jaloul

Site personnel statique (HTML, CSS, un peu de JavaScript), hébergé sur GitHub Pages : https://aymanejal.github.io

Élève ingénieur à l'ENSEEIHT (parcours Architecture, Systèmes et Réseaux), je cherche un stage de 3 mois en réseaux ou en cybersécurité pour l'été 2027.

## Fichiers

```
index.html             contenu du site
style.css              mise en forme
script.js              animation de la console d'accueil
favicon.svg            icône d'onglet
CV_Aymane_Jaloul.pdf   CV
robots.txt             demande aux moteurs de recherche de ne pas indexer le site
```

Pour modifier le site : ouvre `index.html` sur GitHub, clique sur le crayon, modifie, puis « Commit changes ». Le site se met à jour en une à deux minutes.
